# Dados de demonstração

Todos os dados deste projeto são sintéticos. A aplicação foi
inspirada em dificuldades comuns de conferência administrativa,
sem reprodução de informações, documentos ou processos internos
de qualquer empresa.

O arquivo `exemplo_operacional.xlsx` é gerado pelo script
`gerar_dados_sinteticos.py`.

A base contém inconsistências inseridas propositalmente para
demonstrar as regras de validação do PDA Sentinel.
